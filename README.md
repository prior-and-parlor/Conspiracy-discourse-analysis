# Conspiracy Discourse Analysis

This repository contains the research code, analytical workflows, and associated outputs accompanying a manuscript submitted for peer review.

## Repository Contents

1. **Topic Modelling:** Code for topic modelling and associated analyses.
2. **COVID-19 Topic Analysis:** OLS regression models examining COVID-19-related topics, including variable transformations.
3. **Political Dictionary Analysis:** Computational analysis using political dictionaries.
4. **Robustness Checks:** Additional analyses assessing the stability and sensitivity of the findings.

## Reproducibility

Code and analytical outputs are provided to support methodological transparency, independent assessment, and reproducibility.
